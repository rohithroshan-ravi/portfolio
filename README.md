# Portfolio - Rohithroshan R

A modern, responsive portfolio website showcasing my work as a Full Stack Developer.

## 🚀 Features

- **Modern Design**: Built with Next.js, React, TypeScript, and Tailwind CSS
- **Responsive Layout**: Mobile-first design that works on all devices
- **Smooth Animations**: Elegant transitions and animations throughout
- **SEO Optimized**: Proper meta tags, structured data, and performance optimization
- **Dark Mode**: Professional dark theme with gradient accents
- **Fast Performance**: Optimized images, code splitting, and lazy loading

## 📋 Sections

- **Hero**: Eye-catching introduction with call-to-action buttons
- **About**: Personal background and key statistics
- **Experience**: Professional work history and achievements
- **Skills**: Technical expertise and proficiency levels
- **Projects**: Featured portfolio projects with details
- **Contact**: Contact form and social links

## 🛠️ Tech Stack

- **Frontend**: React 18, Next.js 14, TypeScript
- **Styling**: Tailwind CSS, PostCSS
- **Deployment**: Vercel or GitHub Pages
- **Tools**: Git, Node.js, npm

## 📦 Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

## 🔨 Build & Deploy

### Build
```bash
npm run build
```

### Start Production Server
```bash
npm start
```

### Deploy to Vercel

1. Push your code to GitHub
2. Connect your repository to Vercel
3. Vercel will automatically deploy on every push

### Deploy to GitHub Pages

Add to `next.config.js`:
```javascript
const nextConfig = {
  output: 'export',
  // ... other config
}
```

Then build and push the `out` folder to your `gh-pages` branch.

## 📝 Customization

### Update Contact Information
Edit the social links and contact details in:
- `components/Footer.tsx`
- `components/Contact.tsx`

### Modify Content
- **Hero**: `components/Hero.tsx`
- **About**: `components/About.tsx`
- **Experience**: `components/Experience.tsx`
- **Skills**: `components/Skills.tsx`
- **Projects**: `components/Projects.tsx`

### Customize Colors
Edit the Tailwind configuration in `tailwind.config.ts`
